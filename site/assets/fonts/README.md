# Fonts

Self-hosted WOFF2, converted with fontTools from the files Anna supplied (5 Sept 2026).

- `recoleta-regular.woff2` — Recoleta Regular (400): all headings. Commercial typeface — licence must cover self-hosted web use for the production domain; embedding flag in the file is "installable" (fsType 0).
- `rubik-regular.woff2`, `rubik-medium.woff2`, `rubik-italic.woff2` — Rubik 400 / 500 / 400 italic: body, navigation, labels, controls. SIL Open Font License 1.1.

Unused weights supplied (Rubik 300, 700, 900 and their italics, Rubik 500 italic) were not converted; the site only uses 400 and 500. The `@font-face` rules are in section 2 of `/css/styles.css`. No third-party font requests.
